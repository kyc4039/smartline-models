| 항목 | 질문 | 값 |

| 담당 분야 | **누가** 고쳐야 하는가 | 기계 정비 / 전기·제어 / 유공압 / 센서·계측 |

## 1. 조치 시점

### 1.1 판정 규칙

위에서부터 차례로 확인하고, **먼저 해당하는 것**으로 정한다.

| 순서 | 조치 시점 | 조건 |
|---|---|---|
| 1 | **즉시 조치** | 안전 위험 = 있음, 또는 가동 상태 = 정지 |
| 2 | **당일 조치** | 품질 영향 = 있음, 또는 가동 상태 = 저하, 또는 추세 = 악화 (단, 빈도 = 1회성이면 제외) |
| 3 | **정기 점검** | 그 외 |

### 1.2 상황 속성 정의

| 속성 | 값 | 정의 |
|---|---|---|
| 안전 위험 | 있음 / 없음 | **지금** 사람이 다칠 수 있는 요인이 노출되어 있음: 화재·연기·타는 냄새, 노출된 도체, 바닥 기름·미끄럼, 부품 비산·낙하 위험, 안전장치의 위험 방향 이상 |
| 가동 상태 | 정상 / 저하 / 정지 | 정지 = 재가동 불가 또는 핵심 기능을 계속 못 함 / 저하 = 속도 저하, 재조작 필요, 멈췄다가 다시 도는 간헐 정지 / 정상 = 영향 없음 |
| 품질 영향 | 있음 / 없음 | 불량 발생, 불량 유출 위험, 검사 신뢰도 저하 |
| 빈도 | 1회성 / 간헐 / 지속 | 1회성 = 이미 조치되어 현재 정상 (원인 불명으로 재발이 의심되면 간헐로 본다) |
| 추세 | 변화없음 / 악화 | 문장에 악화가 **드러날 때만** 악화 (점점, 늘었음, 심해짐, 자주 그럼) |

### 1.3 자주 나오는 사례

| 사례 | 즉시 조치 | 당일 조치 | 정기 점검 |
|---|---|---|---|
| 누유 | 바닥 고임, 미끄럼, 분출 | 계속 떨어짐 | 맺힘, 얼룩 |
| 안전장치 | 멈춰야 할 때 안 멈춤 | 불필요하게 자꾸 멈춤 | 표시만 이상, 기능 정상 |
| 비전 검사 | 검사 불가, 불량을 다 통과시킴 | 오판정 반복 (어느 방향이든) | 화면 품질만 저하, 판정 정상 |
| 표시등·외관 | — | 안전 관련 표시 이상 | 일반 표시등, 도장, 커버 |
| 이미 해결된 고장 | — | 원인 불명, 재발 의심 | 조치 완료, 현재 정상 |

### 1.4 보조 원칙

1. **가능성 원칙**: "나중에 나빠질 수 있다"는 가능성만으로는 조치 시점을 앞당기지 않는다. 단, 안전 위험은 **현재 노출 여부**로 판단한다. (피복이 벗겨져 도체가 보이면 사고 전이라도 안전 위험 있음)
2. **복수 고장**: 한 보고에 고장이 여러 개면 가장 급한 고장 기준으로 정한다.
3. **고위험 설비**: 프레스 #1, 로봇 적재기는 문장만으로 판정이 애매하면 한 단계 앞당긴다. (평가 데이터 라벨링에만 적용, 상황 설계에는 적용하지 않음)

## 2. 담당 분야

### 2.1 담당 범위

| 담당 분야 | 담당 범위 |
|---|---|
| 기계 정비 | 구동부, 베어링, 벨트·체인·스프로킷, 감속기, 금형, 슬라이드, 구조물·체결부, 자재 걸림·정렬, 모터의 소음·진동 |
| 전기·제어 | 전원, 배선, 차단기·퓨즈, 제어반, 릴레이, PLC, 서보·인버터, 통신, 조작 장치(버튼·스위치·터치패널), 안전 스위치류, 모터의 전기적 이상, 비전 PC 하드웨어 |
| 유공압 | 유압 유닛·탱크, 실린더 본체, 밸브, 호스·배관·피팅, 레귤레이터, 공압 그리퍼, 진공 흡착 |
| 센서·계측 | 근접·광전 센서, 인코더, 위치 센서, 안전 감지기류(광커튼, 인터록 감지), 비전 카메라·렌즈·조명·판정 설정 |

### 2.2 경계 부품 판정표 (부품 + 증상)

| 경계 부품 | 기계 정비 | 전기·제어 | 유공압 | 센서·계측 |
|---|---|---|---|---|
| 모터 | 소음, 진동, 베어링 | 안 켜짐, 과열 알람·트립, 타는 냄새 | — | — |
| 그리퍼·흡착 | 기구부 마모·파손 | — | 공압 누설, 흡착력 저하, 패드 찢어짐 | 파지 확인 센서 |
| 실린더 | 브래킷·고정부 | — | 실린더 본체, 동작 불량, 누설 | 위치 감지 스위치 |
| 비전 검사기 | 거치대·브래킷 | PC 하드웨어(전원, 팬, 다운), 통신 | 에어 블로우 | 카메라, 렌즈, 조명, 판정 설정 |
| 안전장치 | — | 스위치류(비상정지, 풀코드, 양수 버튼) | — | 감지기류(광커튼, 인터록 감지, 안전 센서) |
| 신호 이상 | — | 제어반 내부 배선, PLC, 통신 | — | 센서 본체·감도·오염·정렬, 센서 신호 |
| 조작 장치 | — | 버튼, 스위치, 터치패널 | — | — |

### 2.3 판단 원칙

1. 겉으로 보이는 증상이 아니라 **고장을 고칠 1차 담당자**로 판단한다.
   - 예: 양수 버튼 한쪽만 눌러도 슬라이드 하강 → 원인은 버튼 회로 → **전기·제어**
2. 경계 부품은 2.2 판정표를 따른다.
3. 원인을 알 수 없으면 **먼저 진단할 담당**으로 정한다.
   - 알람·전원 관련 → 전기·제어
   - 감지·인식 관련 → 센서·계측
   - 소리·진동·움직임 자체의 이상 → 기계 정비
4. 고장이 여러 개면 가장 급한 고장의 담당으로 정한다.
