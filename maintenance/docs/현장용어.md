# 현장 용어 목록

- 용도: 5단계 학습용 상황 설계에서 부품·증상·표현이 한쪽으로 쏠리지 않도록 골고루 사용한다.
- 담당 분야는 기준표의 담당 범위와 경계 부품 판정표를 따른다.
- 같은 부품이라도 **증상에 따라 담당이 달라지는 경우**는 담당 칸에 함께 적었다.

## 2. 현장 표현

작업자는 기술 용어보다 **의성어, 줄임말, 비유**를 많이 쓴다. 문장화 단계에서 골고루 섞는다.

| 구분 | 표현 |
|---|---|
| 소리 | 끼익, 딱딱, 덜컹덜컹, 쿵, 쾅, 웅, 찌익, 서걱, 쉭쉭, 피슉, 드르륵, 갈리는 소리 |
| 움직임 | 덜덜 떨림, 들썩거림, 꿀렁거림, 튀어 오름, 헛돎, 흘러내림, 멈칫, 버벅거림 |
| 작동 상태 | 먹통, 안 먹힘, 씹힘, 반응 없음, 한 박자 늦음, 꼼짝 안 함, 지 멋대로 움직임 |
| 발열·냄새 | 뜨끈함, 손 못 댈 정도로 뜨거움, 타는 냄새, 탄내, 기름 냄새 |
| 누설 | 맺힘, 번짐, 뚝뚝, 줄줄, 확 샘, 뿜어져 나옴 |
| 빈도 | 가끔, 한 번씩, 아까부터, 아침부터, 계속, 자꾸, 점점, 하루에 몇 번 |
| 영향 | 그래도 돌긴 함, 작업은 됨, 라인 멈춤, 불량 나옴, 재작업, 두세 번 눌러야 됨 |
| 줄임말·구어 | 컨베어, 모타, 실린다, 센사, 판넬, 에어 샘, 다시 켜니 됨 |

## 3. 사용 규칙

1. 5단계 상황 설계에서 **설비별 부품을 골고루** 사용한다. 한 부품이 전체 상황의 10%를 넘지 않게 한다.
2. **담당이 두 개인 부품**(모터, 진동 피더, 인터록)은 두 담당의 상황을 모두 만든다.
3. 6단계 문장화에서 현장 표현을 섞되, **표현의 강도와 조치 시점은 서로 무관하게** 쓴다. (정기 점검에도 "덜컹덜컹 엄청 시끄러움", 즉시 조치에도 "브레이크 밀림 확인")
