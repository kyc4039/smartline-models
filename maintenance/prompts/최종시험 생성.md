# 프롬프트 01: 최종 시험 데이터 생성 (GPT, Gemini용)

## 사용 방법

1. **GPT와 Gemini 각각 새 대화창**에 아래 프롬프트를 그대로 붙여넣는다. (Claude에는 사용하지 않는다. 학습 데이터 생성기이기 때문)
2. 결과 CSV를 저장한다.
   - GPT → `data/raw/test_final_gpt.csv`
   - Gemini → `data/raw/test_final_gemini.csv`
3. 형식만 확인하고(행 수, 열 이름) **문장 내용은 읽지 않는다.** 학습 데이터 생성이 끝날 때까지 봉인한다.
4. 출력이 중간에 끊기면 같은 대화창에 "이어서 출력해줘. 이미 출력한 id는 제외"라고 요청한다.

---

## 프롬프트 (아래 전체를 복사)

```
너는 자동차 부품 공장에서 오래 일한 현장 작업자다.
설비에 이상이 생기면 설비 보전 시스템에 짧은 고장 메모를 남긴다.
AI 분류 모델을 평가할 시험 문장을 만들기 위해, 아래 절차대로 36개의 고장 메모를 작성하라.

[대상 설비]
프레스 #1, 컨베이어, 로봇 적재기, 비전 검사기, 자재 투입기

[작성 절차]
각 메모마다 1) 고장 상황을 먼저 정하고 2) 상황 속성을 정한 뒤 3) 그 상황을 작업자 메모로 쓴다.

[1. 담당 분야: 이 고장을 고칠 1차 담당자]
- 기계: 구동부, 베어링, 벨트·체인, 감속기, 금형, 슬라이드, 구조물·체결부, 자재 걸림, 모터의 소음·진동
- 전기: 전원, 배선, 차단기·퓨즈, 제어반, 릴레이, PLC, 서보·인버터, 통신, 버튼·스위치·터치패널, 비상정지·풀코드·양수 버튼 회로, 모터가 안 켜짐·과열 알람·타는 냄새, 비전 PC 하드웨어
- 유압공압: 유압 유닛·탱크, 실린더, 밸브, 호스·배관·피팅, 레귤레이터, 공압 그리퍼, 진공 흡착
- 센서: 근접·광전 센서, 인코더, 위치 센서, 광커튼·인터록 감지기, 비전 카메라·렌즈·조명·판정 설정
- 겉으로 보이는 증상이 아니라 고칠 사람 기준이다.
  예) 양수 버튼 한쪽만 눌러도 슬라이드가 내려옴 → 버튼 회로 문제 → 전기

[2. 상황 속성]
- safety (안전 위험): 있음 / 없음
  지금 사람이 다칠 수 있는 요인이 노출됨 (화재·연기·타는 냄새, 노출된 도체, 바닥 기름·미끄럼,
  부품 비산·낙하 위험, 안전장치가 멈춰야 할 때 안 멈춤)
- operation (가동 상태): 정상 / 저하 / 정지
  정지 = 재가동 불가 또는 핵심 기능을 계속 못 함
  저하 = 속도 저하, 재조작 필요, 멈췄다가 다시 도는 간헐 정지
- quality (품질 영향): 있음 / 없음  (불량 발생, 불량 유출 위험, 검사 신뢰도 저하)
- frequency (빈도): 1회성 / 간헐 / 지속  (1회성 = 이미 조치되어 지금은 정상)
- trend (추세): 변화없음 / 악화  (점점 심해짐, 횟수가 늘어남 등이 메모에 드러날 때만 악화)

[3. 조치 시점 판정 규칙]
- 상 (즉시 조치): safety = 있음, 또는 operation = 정지
- 중 (당일 조치): quality = 있음, 또는 operation = 저하, 또는 trend = 악화 (단, frequency = 1회성이면 제외)
- 하 (정기 점검): 그 외
- "나중에 나빠질 수 있다"는 가능성만으로는 조치 시점을 앞당기지 않는다.

[4. 개수 배분]
- 담당 분야 4개 × 조치 시점 3개 = 12개 조합, 조합마다 정확히 3개씩 총 36개
- 각 조합의 속성은 위 판정 규칙에 맞아야 한다.
- 5개 설비를 고르게 사용한다.
- 36개 중 12개 이상에는 현장 용어를 넣는다.
  (예: 풀코드, 양수 버튼, 인터록, 인코더, 서보, 인버터, 레귤레이터, 솔레노이드 밸브, 스프로킷, 상사점)

[5. 말투]
- 각 조합의 3개는 서로 다른 말투로 쓴다.
  담담 = 짧은 메모 ("롤러 덜컹거림 이송은 정상")
  과장 = 감정과 의성어가 섞인 구어 ("롤러가 덜컹덜컹 엄청 시끄러움ㅠ 그래도 돌긴 함")
  보고 = 존댓말 설명 ("하단 롤러에서 소음이 발생하나 이송에는 문제가 없습니다.")
- 중요: 말투와 심각도를 일부러 엇갈리게 섞는다.
  하(정기 점검) 조합에도 과장된 메모를, 상(즉시 조치) 조합에도 담담한 메모를 반드시 넣는다.
- 띄어쓰기 생략, 오타, 줄임말을 일부 섞어도 된다.
- 메모만 읽고도 속성을 판단할 수 있도록, 가동 여부·위험·영향에 대한 정보가 메모에 드러나야 한다.
  단 "안전 위험 있음", "품질 영향", "긴급", "즉시 조치", "정기 점검", "담당" 같은 정답 단어는 쓰지 않는다.
- 36개 메모의 상황과 표현이 서로 겹치지 않게 한다.

[출력 형식]
설명 없이 CSV만 출력한다. 첫 줄은 아래 헤더다.
id,equipment,type,safety,operation,quality,frequency,trend,target,style,text
- type: 기계 / 전기 / 유압공압 / 센서
- target: 상 / 중 / 하
- style: 담담 / 과장 / 보고
- text는 반드시 큰따옴표로 감싼다.
- 모든 값은 위에 적힌 표기를 그대로 쓴다.

예시:
id,equipment,type,safety,operation,quality,frequency,trend,target,style,text
1,컨베이어,기계,없음,정상,없음,지속,변화없음,하,과장,"하단 롤러 덜컹덜컹 엄청 시끄러움ㅠ 근데 물건은 잘 넘어감"
```
