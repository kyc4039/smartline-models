# 프롬프트 02: 학습용 상황 설계 (Claude용)

## 핵심
문장을 쓰기 **전에**, 고장 상황을 **사실 정보 단위**로 먼저 만든다.
조치 시점(정답)은 LLM이 정하지 않고, 속성을 보고 **코드가 기준표 규칙으로 계산**한다.

## 사용 방법

1. **Claude 새 대화창**에서 실행한다. (학습 데이터 생성기는 Claude만 사용)
2. 담당 분야별로 **4번** 요청한다. 한 번에 75개 (즉시 25 · 당일 25 · 정기 25)
   - 요청할 때마다 프롬프트의 `[이번 담당 분야]` 한 줄과 `[부품 목록]`만 바꾼다.
   - 부품 목록은 `docs/현장용어.md` 1장에서 **해당 담당 분야의 행만** 골라 붙인다.
     (담당이 두 개인 부품은 해당 증상만)
3. 담당 분야마다 **새 대화창**을 쓴다. (앞 담당의 상황이 섞이지 않게)
4. 저장: `data/raw/scenarios_기계.csv`, `scenarios_전기.csv`, `scenarios_유압공압.csv`, `scenarios_센서.csv`
5. 출력이 끊기면 같은 창에 "이어서 출력해줘. 이미 출력한 no는 제외"
6. 저장 후 `uv run python src/build_scenarios.py` 실행

## 프롬프트 (아래 전체를 복사)

```
너는 자동차 부품 공장의 설비 보전 전문가다.
AI 학습용으로, 설비 고장 "상황"을 사실 정보 단위로 설계하라.
아직 작업자 메모(문장)는 쓰지 않는다. 상황의 사실만 정리한다.

[이번 담당 분야]
기계

[부품 목록] (이 담당 분야가 고치는 부품과 대표 증상)
(docs/현장용어.md에서 해당 담당 분야의 행을 붙여넣기)

[대상 설비]
프레스 #1, 컨베이어, 로봇 적재기, 비전 검사기, 자재 투입기

[상황 속성 정의]
- safety (안전 위험): 있음 / 없음
  지금 사람이 다칠 수 있는 요인이 노출됨: 화재·연기·타는 냄새, 노출된 도체,
  바닥 기름·미끄럼, 부품 비산·낙하 위험, 안전장치가 멈춰야 할 때 안 멈춤,
  설비가 멋대로 움직임
- operation (가동 상태): 정상 / 저하 / 정지
  정지 = 재가동 불가 또는 그 설비의 핵심 기능을 계속 못 함
  저하 = 속도 저하, 재조작 필요, 멈췄다가 다시 도는 간헐 정지
- quality (품질 영향): 있음 / 없음
  불량 발생, 불량 유출 위험, 검사 신뢰도 저하 (비전 오판정은 방향과 관계없이 있음)
- frequency (빈도): 1회성 / 간헐 / 지속
  1회성 = 이미 조치되어 지금은 정상 (원인 불명으로 재발이 의심되면 간헐)
- trend (추세): 변화없음 / 악화
  점점 심해짐, 횟수가 늘어남이 확인될 때만 악화
- "나중에 나빠질 수 있다"는 가능성만으로는 어떤 속성도 바꾸지 않는다.

[조치 시점 판정 규칙] (참고용, 이 규칙에 맞게 속성을 정한다)
- 즉시: safety=있음 또는 operation=정지
- 당일: quality=있음 또는 operation=저하 또는 trend=악화 (단 frequency=1회성이면 제외)
- 정기: 그 외

[개수와 배분]
- 총 75개: 즉시 25개, 당일 25개, 정기 25개
- 각 조치 시점 안에서 5개 설비를 5개씩 고르게
- 한 부품이 75개 중 8개를 넘지 않게, 부품 목록을 골고루 사용
- 같은 조치 시점이라도 속성 조합을 다양하게:
  즉시 = 안전 위험으로 인한 것과 정지로 인한 것을 섞기
  당일 = 품질 영향 / 가동 저하 / 악화 중으로 인한 것을 섞기
  정기 = 이미 해결된 1회성, 가동·품질 영향 없는 지속 이상, 간헐적이지만 영향 없는 것을 섞기
- 아래 경계 사례를 반드시 포함 (해당 담당 분야에 맞는 것만):
  누유 정도(맺힘·계속 떨어짐·바닥 고임), 안전장치 방향(안 멈춤·불필요하게 멈춤),
  비전 오판정과 검사 불가, 이미 해결된 고장, 소리는 크지만 영향 없는 고장,
  조용하지만 기능을 잃은 고장

[situation 작성 규칙]
- 상황을 한두 문장의 사실로 쓴다. 작업자 말투가 아니라 정비 기록처럼 쓴다.
- 속성을 판단할 근거(위험 요인, 가동 여부, 품질 영향, 빈도, 추세)가 모두 들어 있어야 한다.
- 예: "하단 롤러 베어링 마모로 회전 시 소음 발생, 이송 속도와 제품 상태는 정상, 일주일째 변화 없음"

[출력 형식]
설명 없이 CSV만 출력한다. 첫 줄은 아래 헤더다.
no,equipment,part,type,safety,operation,quality,frequency,trend,situation
- type은 이번 담당 분야 값을 그대로 쓴다 (기계/전기/유압공압/센서)
- 속성 값은 위에 적힌 표기를 그대로 쓴다
- situation은 큰따옴표로 감싼다
```
