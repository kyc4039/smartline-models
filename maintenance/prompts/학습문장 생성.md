# 프롬프트 03: 학습용 문장화 (Claude용)

## 핵심
5단계의 상황 하나를 **네 가지 말투**로 쓴다. 정답(조치 시점·담당)은 **보여주지 않는다.**
문장을 쓰는 LLM이 정답을 알면 정답에 맞춰 말투를 과장하거나 누그러뜨리기 때문이다.

## 사용 방법

1. 묶음 만들기: `uv run python src/make_batches.py` → `data/batches/batch_01.csv ~ batch_12.csv`
2. **Claude 새 대화창**에 아래 프롬프트를 붙이고, 맨 아래 `[상황 목록]`에 묶음 파일 내용을 그대로 붙여넣는다.
3. 한 대화창에서 **최대 3묶음**까지 이어서 요청한다. ("다음 묶음이야" + 붙여넣기) 그 뒤에는 새 대화창.
4. 저장: `data/raw/train_01.csv ~ train_12.csv`
5. 출력이 끊기면 같은 창에 "이어서 출력해줘. 이미 출력한 scenario_id와 style 조합은 제외"
6. 모두 저장한 뒤 `uv run python src/build_train.py`

## 프롬프트 (아래 전체를 복사)

```
너는 자동차 부품 공장의 현장 작업자들이 설비 보전 시스템에 남기는 고장 메모를 재현하는 작가다.
아래 [상황 목록]의 각 상황을 네 가지 말투로 각각 한 번씩, 상황당 4개의 메모로 써라.

[네 가지 말투]
- 담담: 감정 없는 짧은 메모. 명사로 끝내거나 단어 나열. (예: "하단 롤러 소음 있음 이송 정상")
- 과장: 감정·의성어·강조가 섞인 구어. 느낌표, ㅠㅠ, "엄청", "완전" 등 허용.
- 보고: 존댓말로 상황을 설명하는 문장. (예: "~가 발생하고 있습니다.")
- 구어: 동료에게 말하듯 반말. 띄어쓰기 생략, 오타, 줄임말 허용. (예: "컨베어 롤러 소리남 근데 잘 돌아감")

[반드시 지킬 것]
1. 상황 설명의 사실을 바꾸지 않는다. 특히 아래 다섯 가지는 메모만 읽고도 알 수 있어야 한다.
   - 사람이 다칠 위험이 있는지 (있다면 무엇이 위험한지, 없다면 굳이 언급하지 않아도 됨)
   - 설비가 정상 가동인지, 느려지거나 끊기는지, 멈췄는지
   - 불량이나 검사 문제가 있는지
   - 지금 계속되는지, 가끔인지, 이미 해결됐는지
   - 점점 나빠지고 있는지
   상황 설명을 그대로 옮기지 말고 작업자의 말로 바꿔 쓴다. ("이송 정상" → "물건은 잘 넘어감")
2. 말투는 사실의 심각도와 무관하다.
   과장 말투라도 없는 위험을 만들지 않고, 담담 말투라도 있는 위험을 빼지 않는다.
   사소한 이상도 과장 말투로는 요란하게, 심각한 고장도 담담 말투로는 짧고 건조하게 쓴다.
3. 정답을 드러내는 단어를 쓰지 않는다:
   긴급, 즉시, 당일, 정기 점검, 정기점검, 담당, 안전 위험, 품질 영향
4. 설비명은 네 메모 중 일부에서만 쓴다. 나머지는 생략하거나 줄여 부른다. (컨베어, 투입기, 로봇 등)
5. 아래 [현장 표현]을 자연스럽게 섞되, 같은 표현을 반복하지 않는다.
6. 메모 길이를 다양하게: 담담은 5~25자, 과장·구어는 15~50자, 보고는 30~80자 정도.

[현장 표현]
소리: 끼익, 딱딱, 덜컹덜컹, 쿵, 쾅, 웅, 찌익, 서걱, 쉭쉭, 피슉, 드르륵, 갈리는 소리
움직임: 덜덜 떨림, 들썩거림, 꿀렁거림, 튀어 오름, 헛돎, 흘러내림, 멈칫, 버벅거림
작동: 먹통, 안 먹힘, 씹힘, 반응 없음, 한 박자 늦음, 꼼짝 안 함, 지 멋대로 움직임
발열·냄새: 뜨끈함, 손 못 댈 정도로 뜨거움, 타는 냄새, 탄내, 기름 냄새
누설: 맺힘, 번짐, 뚝뚝, 줄줄, 확 샘, 뿜어져 나옴
빈도: 가끔, 한 번씩, 아까부터, 아침부터, 계속, 자꾸, 점점, 하루에 몇 번
영향: 그래도 돌긴 함, 작업은 됨, 라인 멈춤, 불량 나옴, 재작업, 두세 번 눌러야 됨
줄임말: 컨베어, 모타, 실린다, 센사, 판넬, 에어 샘, 다시 켜니 됨

[출력 형식]
설명 없이 CSV만 출력한다. 첫 줄은 헤더다.
scenario_id,style,text
- 상황마다 담담, 과장, 보고, 구어 순서로 4행
- style 값은 담담/과장/보고/구어 중 하나
- text는 큰따옴표로 감싼다

[상황 목록]
(data/batches/batch_XX.csv 내용을 붙여넣기)
```
